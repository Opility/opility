## 🚀 Getting Started

### For Customers
Visit [opility.com](https://opility.com) to:
- Explore our courses and services
- Schedule a consultation
- Access the learning platform

### For Developers
1. **Clone a starter kit:**
   ```bash
   git clone https://github.com/Opility/opility-dev.git
   cd opility-dev
   npm install
   npm run dev
   ```

2. **Explore AI playbooks:**
   - See [opility-ai](https://github.com/Opility/opility-ai) for production-ready prompt templates

3. **Access QA frameworks:**
   - See [opility-qa](https://github.com/Opility/opility-qa) for testing patterns and collections

4. **Integrate with your workflows:**
   - Use Apify actors for web data extraction
   - Leverage Zapier integrations for business automation
   - Deploy via Vercel or Cloudflare Pages
